# 评估 · 其余四页 LCP 同成因（指令69 A4，只评估未开发）

> 问题：指令68 A6 实测报销/工资/报表/help 四页本地 LCP ~790–810ms，
> 与总览 T1 处理前同量级，疑为同一成因（容器 fadeUp 钉点）。本评估
> 只做小样测量与观感评估，**未动任何业务代码**；是否推广 `.no-enter`
> 等处理方式，等督工裁定。

## 测法

- 本地演示构建（老板会话，1440），五页（含总览作对照）× 三变体 ×
  5 次加载取中位；记录 LCP、LCP−FCP 与 LCP 元素。
- 变体经 Playwright `page.route` 拦截 CSS 响应、追加覆盖规则实现
  （测完即弃的临时脚本，未进仓、未改源码）：
  - 变体一「仅关容器」：`.container{animation:none!important}`；
  - 变体二「关容器+卡片」：再加 `.card,.kpi-card{animation:none!important}`。

## 实测（LCP 中位 / LCP−FCP 中位 / LCP 元素）

| 页面 | 原样 | 仅关容器 | 关容器+卡片 | LCP 元素 |
|---|---|---|---|---|
| 总览 /（对照，已 .no-enter） | 208ms / 68ms | 200ms / 52ms | 180ms / 36ms | 演示横幅文本或英雄数字 |
| 报销 /expenses | 808ms / 672ms | **136ms / 0ms** | 144ms / 0ms | 页标题 H1「报销」 |
| 工资 /salary | 800ms / 656ms | **152ms / 0ms** | 152ms / 0ms | 页标题 H1「工资」 |
| 报表 /reports | 800ms / 656ms | **144ms / 0ms** | 144ms / 0ms | 首段说明文本 |
| help /help | 792ms / 672ms | **152ms / 0ms** | 128ms / 0ms | 页标题 H1「操作手册」 |

与 perf 协议口径互证：本轮 A2 第九轮四页 LCP 808/792/780/812ms，
与上表「原样」逐页同量级。

## 结论：同成因坐实，且钉点只来自容器一处

1. 四页 LCP 元素都是**页标题/首段文本**（DOM 靠前内容），不是数字
   或图片；其有效绘制被 `.container` 的 `fadeUp 0.55s backwards`
   整体钉到动画末段，与总览 T1 前的机制完全相同（62-A5/68-T1 已
   定性），只是总览当年被钉的是英雄数字、本四页被钉的是标题文本。
2. 只关容器动画即全部归零（LCP−FCP=0、LCP 落到 128–152ms）；
   再关 `.card/.kpi-card` 动画**无额外收益**（差异在噪声内）——
   卡片阶梯淡入不钉这四页的 LCP（LCP 元素不在卡片内）。
3. 总览对照的残余 36–68ms 来自次级卡阶梯动画对个别落点的影响，
   量级小，不在本评估范围。

## 观感评估

- 容器 fadeUp 是整页 0.55s 的轻微上浮淡入，全站每页一致（总览已于
  T1 单独免除）。四页 LCP ~800ms 距 2.5s 待查线有 3 倍余量，**用户
  无可感知问题**，处理收益纯为指标与一致性。
- 若只给这四页免除，会出现三档并存：总览+四页无入场、其余页
  （仪表盘/成本/对比/构成/成员/状态）仍有入场——同板块内页面切换
  时观感反而更参差。

## 选项（等裁定，本轮不执行）

- **甲（若处理，推荐形态）**：全站 `.container` 统一免入场（或统一
  改为不钉绘制的呈现方式），一笔处理、观感回到全站一致；预期五页
  LCP 全部落到 ~130–210ms。代价：整站失去页面入场上浮感（总览已
  先行如此，实际观感差异小）。
- **乙**：只推广 `.no-enter` 到本四页——指标达标，但形成上述三档
  并存，不推荐。
- **丙**：维持现状——指标在待查线内 3 倍余量，观感全站一致（除
  总览），零改动风险；待整站改版时一并决定。

本评估倾向：**丙可接受、甲可采纳、乙不取**，请督工裁定。
