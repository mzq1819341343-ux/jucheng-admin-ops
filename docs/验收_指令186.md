## 4. 运行方式

```bash
python3 docs/fetch-pipeline/auto_fetch.py --check    # 管道自检（不登录不抓数）
python3 docs/fetch-pipeline/auto_fetch.py --once --input <官网后台原生导出文件>   # 规范化落盘一份样本
```

- 定时：本轮未启用（crontab / launchd 均为注释态备置）；即便日后启用，`UPLOAD=false` 不变，只抓取落盘。
