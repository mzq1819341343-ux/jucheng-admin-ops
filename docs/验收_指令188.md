## 如何实现（各三句）

**墨迹扫入**：`@keyframes inkChar` 主效果改为 `clip-path: inset(0 100% 0 0) → inset(0 0 0 0)`，每字自左向右拭入，辅以 opacity 0→1（55% 处已满）与 translateY(2px)→0，blur 不再参与。时序沿用组件内联 delay 0.25s 起、每字 +75ms，单字时长 0.55s，末字 1.0s 起笔、**1.55s 落稳**（≤720px 时长缩为 0.42s，1.42s 落稳）。span 自首帧即占位（backwards 填充），容器尺寸不变；落稳后保留静态轻金 glow（text-shadow），字本身不循环闪烁。

**科技层**：`.login-tech` 绝对定位铺满 `.login-wrap`，`z-index:-1` 与既有网格（`::before`）同层、`overflow:hidden` 自裁切、`pointer-events:none` 不挡表单，纯 CSS 零 JS。光点 6 个（金 4 + 淡青金 2）以径向渐变作光晕，呼吸动画周期 4.8–7.1s 错开、透明度 0.14↔0.5；能量线 2 条为 1px 金色渐变条，-14° 对角以 transform 平移扫过，单圈 9s / 12.5s、低对比、走上沿与下沿不穿表单中央。≤720px 光点减为 4 个、能量线只留 1 条；减动效下光点静态低透明、能量线隐藏。

**减动效**：登录作用域 `@media (prefers-reduced-motion: reduce)` 显式关停——`.ink-char` animation:none、opacity:1、无 clip/transform，口号首帧即完整；`.tech-dot` 动画停、静态低透明；`.tech-line` 隐藏；网格静态保留（另有全局降级规则兜底）。

## 已知限制与二期建议（本轮不做）

- 墨迹为 clip-path 直线拭入，是「书写感」而非真实笔顺；字体在无楷体环境回退宋体，笔锋感弱于 Mac/iOS。
- 光点位置为固定百分比布局，超宽屏下分布偏疏；能量线为 CSS 渐变条，无轨迹随机性。
- 二期可选：为 10 个汉字预制书法 SVG（mask + dashoffset）替换 span 字面，或内联 AnimCJK 子集并染金色；科技底可加稀疏 canvas 能量线（必须 pointer-events:none + aria-hidden + 减动效可关），仍守性能预算。
