# 爱回收驾驶舱 · crontab 示例（未启用）
#
# 两种用法二选一，不要与 launchd 示例同时启用，避免重复跑：
# A) Muse 定时任务（推荐）：在 Muse 里建 cron 任务唤起 agent，
#    在已登录的 Muse 浏览器中只读导出 + 跑 v3，时区 Asia/Shanghai；
#    这种方式不需要下面的 crontab，本文件仅作本地备选说明。
# B) 用户 Mac 本地 crontab：只能做提醒与（文件已备好时的）重算，
#    本地脚本无法复用 Muse 浏览器会话，导出仍需用户本人完成登录后操作。
#
# 安装（方式 B）：把 GOAL 改成本机项目根目录绝对路径后执行
#   crontab -e   （粘贴下面两行）
# 停用：crontab -e 删除对应行即可。
# 时区：cron 按本机系统时区运行，本机应为 Asia/Shanghai。
# 注意：macOS 上 date 取上月用 `date -v-1m +%Y-%m`；Linux 用 `date -d last-month +%Y-%m`。

# 每日 09:30：检查前一日增量（骨架；会话不可用时立即停并写状态，不重试登录）
30 9 * * * /usr/bin/python3 GOAL/muse_v3/auto_fetch/auto_fetch.py --date "$(date -v-1d +%Y-%m-%d)" >> GOAL/muse_v3/auto_fetch/status/cron.log 2>&1

# 每月 3 日 10:00：抓上月整月（订单 + 对账单 + 列表金额）
0 10 3 * * /usr/bin/python3 GOAL/muse_v3/auto_fetch/auto_fetch.py --month "$(date -v-1m +%Y-%m)" >> GOAL/muse_v3/auto_fetch/status/cron.log 2>&1
