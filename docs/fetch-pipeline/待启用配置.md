## 失败处理（已定）

- **会话失效 / 落到登录页 / 出现验证码**：立即停手，在同目录《状态记录.md》追加一条 `need_user_login`（日期时间 + 停在哪一步），并在 Supabase fetch_logs 记一条 status='need_user_login'（有写入口时）。**不重试登录、不猜密码、不绕验证码**，等老板本人在 Muse 浏览器面板登录一次后补跑。
- 校验失败（驾驶舱退出码 3）：保留上一份有效驾驶舱不覆盖，按 v3 门禁规则本月不出建议、不做验收回顾。
- 导出不完整（缺店 / 缺列 / 对账单工作表不全）：不落盘、不并入 data，只记录缺项。
- 列表金额读不到：不填 0，标并记录。
