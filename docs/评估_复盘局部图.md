## 逐项判定（达标线沿 62-A4 四维）

1. **体积：达标。** 口径 B 量化后 40,487B，低于同类区块图量级
   （≤~100KB），PSNR 67.7dB 远超 40dB 线；守线（基线 ×1.3）可纳管。
2. **信息量：达标。** 6 行即含四状态中的三分支 + 未设定，与 62 轮整表
   图「27 行只有 3 行有效」相比密度已达标——局部化解决了信息量问题。
3. **版面：不达标。** 两处硬伤：(i) 处方构图（行 + 按钮）最小单幅高
   469px，超 300–400px 线约 17%——脚注两行夹在表与按钮之间，矩形裁切
   无法跳过；(ii) 无表头、无节标题：六列（月份/口径/目标/实际/达成率/
   状态）列义不可自明，读者只能靠 /help 正文猜列，且裁切线在行间、
   顶部露邻行边线。既有八图均为含标题/表头的完整区块，本图与图集
   构图规范不一致。口径 A 虽高 327.5px 达标，但丢了处方要求的双按钮
   区，属变更范围，须另行裁定，不在本评估内擅自替换。
4. **维护：中性偏负（同 62 轮）。** 同步面 ≥6 处（capture-help-shots
   截图步 + 量化名单、audit-online 文件清单/守线双表/图注 8→9 处断言、
   /help 图注与引用、运维清单）；版面不达标前提下不投入。

## 结论与重议条件

**不达标，保留八图。** 局部化已证明信息量与体积可达标，卡点只在
版面：表头/标题与目标区不相邻 + 处方构图超高。重议触发（满足其一

≤400px 内完整构图；届时按四维重新试截判定，不沿用本结论直接开工。
